# 🛠️ Landing Page - Oficina Mecânica
![Preview da Landing Page](assets/preview.png)

Landing page moderna e responsiva desenvolvida para uma oficina mecânica. O projeto foi construído do zero, transformando os logotipos e a identidade visual fornecidos pelo cliente em um layout intuitivo focado em conversão.

## 🚀 Funcionalidades

* **Apresentação da Marca:** Seção principal com destaques dos diferenciais da oficina.
* **Catálogo de Serviços:** Exibição clara dos principais procedimentos (revisão, freios, suspensão, troca de óleo, etc.).
* **Call to Action (CTA):** Botões direcionando diretamente para agendamento via WhatsApp.
* **Localização e Contato:** Informações de endereço, horário de funcionamento e mapa interativo.
* **Design Responsivo:** Adaptado para navegação fluida em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
